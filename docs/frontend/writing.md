# 写作工作面

阅读和写作是主窗口里的两个画面。编译、SyncTeX、编辑器和论文库引用仍走原来的能力，见 [LaTeX](latex.md)。

## 切换

左侧栏标题下是「阅读 / 写作」。

- **阅读**是文件树和中间的工作区。论文库是这里的常驻标签。打开 TeX 时，左栏不再放编译命令和大纲。
- **写作**盖住中间的工作区。论文库留在下面，不出现在写作画面里。左栏是项目、源文件和结构。结构一直展开。文件树保持挂载，切回阅读时展开状态还在。
- 方向键在两个选项之间移动。选中项才进 Tab 序。

上次停在哪个画面记在本机 `agentero.writing.v1`，按 Vault 分开。

## 项目

`thesis/` 是放项目的目录，本身不是一篇稿子，阅读的文件树里不显示它。每个能独立解析出主文件的 TeX 根是一个项目，各自编译。章节如果解析回父级主文件，就留在那个项目里。

你改过主文件里的 `\title`（ICML 是 `\icmltitle`）之后，列表用这篇论文的标题。官网模板自带的示例标题不当作项目名，这时用新建时的文件夹名。没有标题、目录名又是 `thesis` 时，再用主文件名。`main` / `thesis` 也不拿来当名字，界面显示「未命名项目」。

写作首页列出已有项目，并可以新建。左栏项目菜单里的「新建项目」会打开名称和模板：空白稿，或 CVPR/ICCV、ICML、ICLR、NeurIPS、ACL/EMNLP、ECCV。会议模板是官网压缩包里的源文件，原样放进 `thesis/<名称>/`，不改写标题。来源见 `src/lib/writing/templates/vendor/SOURCES.md`。一个项目的文件列表不包含旁边的其他项目。删除项目只在全部项目这一页，项目菜单里没有删除。

文件行可以右键，也可以点右侧菜单。文件可以重命名、下载、删除、复制路径、在系统文件管理器中显示、在终端中打开，或加到对话。`.tex` 文件还可以设为主文件，之后编译、预览和大纲都用它。文件夹可以新建文件、新建文件夹、上传，子文件夹还可以重命名和删除。编译产生的 PDF 仍不出现在列表里。

点源文件会在写作顶部打开一个标签。右键可以关闭、关闭其他或关闭全部；只剩一个标签时也可以关闭，项目和右侧 PDF 还在。编辑区顶部是固定工具条：在 PDF 中定位、从论文库插入引用、字号。编辑区和 PDF 之间可以拖动分隔条。

PDF 上方一行的左边是编译、历史、上传、问题数量和编译日志。问题数量和编译日志打开同一张列表：左边是编辑器检查和编译日志里的警告与错误，右边是原始日志，点一条会跳到源文件并滚到对应日志。编译引擎按主文件的 `% !TEX program`、你为这个项目选过的引擎、模板要求的引擎（CVPR、ICLR、ICML、NeurIPS、ACL、ECCV 用 pdfLaTeX；带 `babelfont` 的用 LuaLaTeX）来决定，没有这些时才用 XeLaTeX。引擎、项目设置、GitHub 仓库和何时上传都在应用设置的「写作」里。上传可以是手动、每次编译后，或每 5、15、30、60 分钟。默认是每次编译后；还没填写仓库时不会上传。页面背景在页码和缩放左边。阅读里的论文库和文档标签留在「阅读」。

「历史」打开后占住编辑区：左边是每次上传，右边是这一版改动的文字。可以回退到选中的那一版，回退只改工作区里的文件，不删掉之后的上传记录。列表顶部是还没上传的修改。保存源文件不会另记一份本地快照。上传把整个 `thesis/` 提交并推送到这个仓库，编译产物和 PDF 不上传。没有改动时不会多出一条记录。还没登录时，由本机 Git 打开系统登录窗口。没有 Git，或写作目录和远端改动对不上时，不会覆盖任何一边，自动上传也会停下来，等你再点一次上传。

删除项目会把该项目目录放进 Vault 的回收站（`.agentero/.trash/`），不是直接抹掉。`thesis/` 这一层是书架，不能整层删掉。直接放在 `thesis/` 里的稿件（例如种子文件 `thesis/main.tex`）按这一个文件删除，旁边的项目文件夹留下。项目菜单里的「回收站」在写作画面里列出同一份回收站，可以恢复。Windows 上编译把引擎输出写到临时文件再读，避免 pdfTeX 在管道上 `fflush` 失败。

## 还没做

文件树上不再提供编译。写作时 Agent 的默认上下文是当前打开的稿件，不再沿用阅读里的论文。空对话提供续写、收紧文字、检查论证，以及从文库起草带引用的下一段。源码和编译后的 PDF 都可以划词后加入对话或快速提问。编译问题列表里可以把这一条交给 Agent，并带上所在文件和行。Agent 回复里指向 `thesis/` 源文件的链接会在写作编辑器里打开。同步不会替你创建 GitHub 仓库，也不会在应用里保存密码。
