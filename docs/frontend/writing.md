# 写作工作面

阅读和写作是主窗口里的两个画面。编译、SyncTeX、编辑器和论文库引用仍走原来的能力，见 [LaTeX](latex.md)。

## 切换

左侧栏标题下是「阅读 / 写作」。

- **阅读**是文件树和中间的工作区。论文库是这里的常驻标签。打开 TeX 时，左栏不再放编译命令和大纲。
- **写作**盖住中间的工作区。论文库留在下面，不出现在写作画面里。左栏是项目、源文件和结构。结构一直展开。文件树保持挂载，切回阅读时展开状态还在。
- 方向键在两个选项之间移动。选中项才进 Tab 序。

上次停在哪个画面记在本机 `agentero.writing.v1`，按 Vault 分开。

## 项目

`thesis/` 是放项目的目录，本身不是一篇稿子，阅读的文件树里不显示它。`thesis/` 下的一级文件夹各自是一个项目：文件夹里有 TeX 文件就出现在左栏项目菜单里，空的或只有非 TeX 文件的文件夹不算项目。项目菜单顶部的「新建项目」用一个下拉面板填名称、选模板后创建；项目行悬停时右侧出现删除按钮，点它把该项目的文件夹移到 Vault 回收站（`.agentero/.trash/`），`thesis/` 这一层不动。重命名在 Finder、终端或 Agent 里进行，应用监听文件树变化并更新菜单。每个项目优先取 `main.tex`（没有时取与文件夹同名的 `.tex`，再取第一个 `.tex`，也允许主文件放在一级子文件夹里）作为主文件，各自编译。

你改过主文件里的 `\title`（ICML 是 `\icmltitle`）之后，列表用这篇论文的标题。官网模板自带的示例标题不当作项目名，这时用文件夹名。目录名是 `thesis` 或没有可读标题时，再用主文件名。`main` / `thesis` 也不拿来当名字，界面显示「未命名项目」。

写作模式直接进入一个项目：上次打开的项目文件夹还在就打开它，否则打开列表里的第一个；`thesis/` 下没有项目时显示空状态。左栏项目菜单列出所有项目文件夹，点击切换。一个项目的文件列表不包含旁边的其他项目。

文件行可以右键打开操作菜单。文件可以重命名、移动、剪切后粘贴到项目内的文件夹、下载、删除、复制路径、在系统文件管理器中显示、在终端中打开，或加到对话。`.tex` 文件还可以设为主文件，之后编译、预览和大纲都用它。文件夹可以新建文件、新建文件夹、上传，也可以剪切、粘贴、移动、重命名和删除。移动只在当前项目的文件夹里选目标，不会把章节挪到别的项目。编译产生的 PDF 仍不出现在列表里。左栏打开项目后直接从根目录的文件开始，不显示项目文件夹这一行；在文件列表的空白处右键可以新建文件、新建文件夹、上传，或粘贴剪切的内容。文件行和结构大纲的字号、图标以及悬浮、选中状态与阅读文件树一致。

点源文件会在写作顶部打开一个标签，标签沿用阅读区的 Dockview 标签样式。右键可以复制路径、在系统文件管理器中显示、在终端中打开、加到对话，以及关闭、关闭其他或关闭全部；只剩一个标签时也可以关闭，项目和右侧 PDF 还在。编辑区右上角是悬浮工具条：插入引用、字号。编辑区和 PDF 之间可以拖动分隔条。

源码与 PDF 分隔条约三分之一高度处的按钮使用随主题切换的浮层配色，悬停时显示手形光标；按钮独立于拖拽区域，点击不会调整分栏宽度。→ 无选区时按源码光标定位 PDF；有选区时查询所选非空源码行的起止位置，保留并去重 SyncTeX 返回的排版区域，跨行、跨栏、跨页分别高亮，不合并成整页大框。快捷键与按钮使用同一选区逻辑。高亮精度受编译生成的 SyncTeX 映射限制，可能覆盖整条排版行，并非逐字符选区；← 优先使用当前 PDF 最近一次点击的页内位置，与双击或 ⌘/Ctrl + 点击同一点使用相同的 SyncTeX 查询。双击 PDF 直接跳到对应源码，无需按修饰键。悬停或键盘聚焦箭头时，在右侧显示跳转方向提示；← 额外提示双击 PDF 可更准确地定位，→ 显示定位快捷键。普通点击只记录位置，不跳转；缩放或滚动不会改变已记录的 PDF 坐标。尚未点击时，← 使用当前页可见区域中心；重新加载 PDF 后清除旧位置。此同步能力适用于编译后的 PDF，实时预览尚未接入。

PDF 上方一行的左边是编译按钮和黄色叹号入口；编译按钮旁的下拉菜单可以打开实时预览（需要 LuaLaTeX 和 realtime-tex 支持文件），打开后 PDF 右上角显示带状态圆点的「实时预览」卡片；点叹号打开问题小卡片，列出编辑器检查与编译日志里的警告和错误，卡片底部的「编译日志」进入完整列表：左边是问题，右边是原始日志，点一条会跳到源文件并滚到对应日志。最右侧是带文字的历史与上传按钮。编译引擎按主文件的 `% !TEX program`、你为这个项目选过的引擎、模板要求的引擎（CVPR、ICLR、ICML、NeurIPS、ACL、ECCV 用 pdfLaTeX；带 `babelfont` 的用 LuaLaTeX）来决定，没有这些时才用 XeLaTeX。引擎、项目设置、GitHub 仓库和何时上传也在应用设置的「写作」里；还没连接仓库时，点上传会在编辑区新开一个「上传」标签页，在里面填仓库、选上传时机并上传，不再打开设置窗口。上传可以是手动、每次编译后，或每 5、15、30、60 分钟。默认是每次编译后；还没填写仓库时不会上传。PDF 底部悬浮页码、缩放滑动条和页面背景，位置与顺序和阅读里的 PDF 一致。阅读里的论文库和文档标签留在「阅读」。

「历史」在顶部新开一个「修改历史」标签页，和源文件标签并列，可以切换或关闭：左边是每次上传，右边是这一版改动的文字。可以回退到选中的那一版，回退只改工作区里的文件，不删掉之后的上传记录。列表顶部是还没上传的修改。保存源文件不会另记一份本地快照。上传把整个 `thesis/` 提交并推送到这个仓库，编译产物和 PDF 不上传。没有改动时不会多出一条记录。还没登录时，由本机 Git 打开系统登录窗口。没有 Git，或写作目录和远端改动对不上时，不会覆盖任何一边，自动上传也会停下来，等你再点一次上传。

项目文件夹在应用外移走或删除后，项目菜单会在文件树刷新时更新；当前项目消失时自动切到列表里的第一个。`thesis/` 这一层是书架，不当作项目。Windows 上编译把引擎输出写到临时文件再读，避免 pdfTeX 在管道上 `fflush` 失败。

## 还没做

文件树上不再提供编译。写作时 Agent 的默认上下文是当前打开的稿件，不再沿用阅读里的论文。空对话提供续写、收紧文字、检查论证，以及从文库起草带引用的下一段。源码和编译后的 PDF 都可以划词后加入对话或快速提问。编译问题列表里可以把这一条交给 Agent，并带上所在文件和行。Agent 回复里指向 `thesis/` 源文件的链接会在写作编辑器里打开。同步不会替你创建 GitHub 仓库，也不会在应用里保存密码。

诊断共享类型定义在 `src/lib/tex/editor-diagnostic.ts`，编辑器 UI 和 lint bridge 均依赖该契约，避免 lib 层反向依赖组件。
