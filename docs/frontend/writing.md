# 文稿工作面

阅读和文稿是主窗口里的两个画面。编译、SyncTeX、编辑器和论文库引用仍走原来的能力，见 [LaTeX](latex.md)。

## 切换

左侧栏标题下是「阅读 / 文稿」。

- **阅读**是文件树和中间的工作区。论文库是这里的常驻标签。打开 TeX 时，左栏下方仍是编译和大纲；否则是论文信息。
- **文稿**盖住中间的工作区。论文库留在下面，不出现在写作画面里。左栏换成项目、源文件、编译和大纲。文件树保持挂载，切回阅读时展开状态还在。
- 方向键在两个选项之间移动。选中项才进 Tab 序。

上次停在哪个画面记在本机 `agentero.writing.v1`，按 Vault 分开。

## 项目

`thesis/` 是放项目的目录，本身不是一篇文稿，阅读的文件树里不显示它。每个能独立解析出主文件的 TeX 根是一个项目，各自编译。章节如果解析回父级主文件，就留在那个项目里。

名称优先用主文件里的 `\title`。没有标题时用所在目录名；目录名就是 `thesis` 时，再用主文件名。`main` / `thesis` 也不拿来当名字，界面显示「未命名项目」。

文稿首页列出已有项目，并可以新建。新建时先选模板：空白稿，或 CVPR、ICML、ICLR、NeurIPS、ACL 的投稿样式。会议样式是官方文件，原样放进 `thesis/<名称>/`，来源见 `src/lib/writing/templates/vendor/SOURCES.md`。主文件用项目名做标题，然后打开它。左栏的项目菜单可以换项目、回到全部项目，或再建一个。

点源文件会在文稿顶部打开一个标签。右键可以关闭、关闭其他或关闭全部；只剩一个标签时也可以关闭，项目和右侧 PDF 还在。编译出的 PDF 不进文件列表，只在右侧预览。阅读里的论文库和文档标签留在「阅读」。实时预览仍属于阅读里的标签。新建项目在文稿首页。
